🐾 Adotfy

Plataforma web para adoção de animais, conectando ONGs a pessoas interessadas em adotar de forma consciente, simples e rápida.

🔗 Acesse o projeto em: https://adotfy.vercel.app

📌 Sobre o projeto

O Adotfy foi desenvolvido com o objetivo de facilitar o processo de adoção responsável de animais, criando uma ponte entre ONGs e possíveis adotantes.

A aplicação apresenta uma navegação simples, com páginas dedicadas para:

Área institucional
Visualização de pets disponíveis
Cadastro de ONGs
Divulgação de animais perdidos
Login exclusivo para ONGs


A estrutura do projeto utiliza componentes react, além de consumir dados de uma API para a renderização dinâmica da lista de pets disponíveis.

🚀 Funcionalidades:
 - Listagem de pets disponíveis para adoção.
 - Navegação entre páginas (home, pets, ONGs, sobre, animais perdidos).
 - Cadastro de ONGs interessadas em participar do projeto.
 - Área de login para ONGs.
 - Página institucional explicando o projeto.
 - Seção de pets e conteúdo dinâmico.

🛠️ Tecnologias utilizadas
 - HTML5
 - CSS3
 - Javascript (React)
 - Pyhton (Flask)
 - SQLite
 - Vite

⚠️ Status do projeto

O projeto está funcional em nível de front-end e integração com API, porém ainda possui funcionalidades em desenvolvimento:

❌ Dashboard para cadastro de pets.
❌ Dashboard para gerenciamento de ONGs.
⚠️ Fluxo de autenticação ainda não integrado ao back-end.

Essas funcionalidades já foram planejadas e fazem parte da evolução do sistema.
